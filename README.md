### 🧪 奇思妙想 (Experimental)

我喜欢做一些神奇的东西：

*   **[UnusualChineseChess](https://github.com/Samera2022/UnusualChineseChess)** ♟️
    *   “规则还是那个规则，但玩法绝对让你大吃一惊。”
    *   支持局域网对战、残局导入导出，以及各种魔改玩法（比如“堆叠棋子”）。
*   **[DictionaryViewer](https://github.com/Samera2022/DictionaryViewer)** 📖
    *   专门针对微软拼音输入法二进制词典文件的可视化解析工具。
*   **[AdvancedClipboard](https://github.com/Samera2022/AdvancedClipboard)** 📋
    *   基于 C++ 开发的轻量级系统托盘剪贴板增强工具，支持文本与图片历史记录。
